## MicroPython device support

MAGPIE has no dependency on, whitelist for, or restriction to a board family. It runs on all MicroPython devices. Availability of a particular transport or hardware example follows the runtime capabilities and peripherals exposed by that device's MicroPython environment, not its board brand or processor family.

## Known cross-language consideration

C++ currently places WebRTC image and audio frames on the data channel. When pairing C++ with Python, disable native media channels in Python (`use_media_channels=False`) and C++ (`useMediaChannels=false`). Python-to-browser deployments can use native media tracks when both peers declare the same media topics.
