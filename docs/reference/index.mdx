## Shared conceptual surface

| Concept | Python | C++ | TypeScript |
|---|---|---|---|
| Streaming base | `StreamWriter`, `StreamReader` | `StreamWriter`, `StreamReader` | `StreamWriter`, `StreamReader` |
| RPC base | `RpcRequester`, `RpcResponder` | `RpcRequester`, `RpcResponder` | `RpcRequester`, `RpcResponder` |
| MQTT connection | `MqttConnection` | `MqttConnection` | `MqttConnection` |
| WebRTC connection | `WebRTCConnection` | `WebRtcConnection` | `WebRtcConnection` |
| Method schema | `JsonRpcSchema` | `JsonRpcSchema` | `JsonRpcSchema` |
| MCP tools | `McpSchema`, `McpTransport` | `McpSchema` server | `McpSchema`, `McpTransport` |

Use the language pages for exact spelling and lifecycle behavior. Use [Compatibility](/docs/reference/compatibility) before planning a mixed-language deployment.

## Stability guidance

MAGPIE is under active development and the three packages release independently. Pin versions in production, read repository release notes, and test cross-language contracts before rolling out a new combination.
