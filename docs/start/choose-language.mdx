# Choose a language

All MAGPIE implementations share the same communication model and wire formats. Choose based on where your application runs; a single system can freely mix languages.

| | Python | C++ | TypeScript / JavaScript | MicroPython |
|---|---:|---:|---:|---:|
| ZeroMQ | ✓ | ✓ | — | ✓ |
| MQTT | ✓ | ✓ | ✓ | ✓ |
| WebRTC | ✓ | ✓ | ✓ Browser | — |
| Streaming and RPC | ✓ | ✓ | ✓ | ✓ async |
| Typed frames | ✓ | ✓ | ✓ | ✓ |
| Schema RPC | ✓ | ✓ | ✓ | ✓ |
| MCP tool server | ✓ | ✓ | ✓ | ✓ |
| MCP client adapter | ✓ | Via Python client | ✓ | Via desktop client |
| Node helpers | ✓ | ✓ | — | — |
| Network discovery | ✓ | ✓ | — | — |
| CLI and SSH tools | ✓ | — | — | — |

## Python

Choose Python for AI services, orchestration, rapid prototyping, CLI automation, media processing, or when you want the broadest MAGPIE feature set.

```bash
pip install luxai-magpie
```

[Python reference →](../reference/python) · [Python repository](https://github.com/luxai-qtrobot/magpie)

## C++

Choose C++ for native robot applications, embedded Linux, low-overhead processing, or integration into an existing CMake codebase. MAGPIE C++ targets C++14 and provides optional MQTT, WebRTC, audio, and video libraries.

[C++ installation →](./installation?language=cpp) · [C++ reference →](../reference/cpp) · [C++ repository](https://github.com/luxai-qtrobot/magpie-cpp)

## TypeScript and JavaScript

Choose MAGPIE.js for browser interfaces, web-based robot control, Node.js services, and browser-native WebRTC media. The npm package includes TypeScript declarations and a CDN bundle.

```bash
npm install @luxai-qtrobot/magpie
```

[TypeScript reference →](../reference/typescript) · [JavaScript repository](https://github.com/luxai-qtrobot/magpie-js)

## MicroPython

Choose MicroPython for any MicroPython device that needs to stream sensor data, expose RPC services, or serve MCP tools without a desktop operating system. MAGPIE runs on all MicroPython devices and has no dependency on a board family. The default direct ZMQ transport needs no broker; MQTT is available through an optional manifest. Memory, dependencies, and queues remain deliberately bounded.

```powershell
mpremote connect COM13 mip install github:luxai-qtrobot/magpie-upy
```

[MicroPython quickstart →](../examples/micropython) · [MicroPython API →](../reference/micropython) · [MicroPython repository](https://github.com/luxai-qtrobot/magpie-upy)

:::info Mixing languages is expected
A MicroPython sensor can connect directly to Python or C++ over ZMQ, or use optional MQTT when a broker, browser, or NAT-friendly topology is needed. See [cross-language systems](../examples/cross-language) for the rules that keep them interoperable.
:::
